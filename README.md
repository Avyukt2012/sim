# LF3 Line Follower Run Simulator

Watch the LF3 line follower program (`LF3_Line_Follower.ino`) drive the 3.53 m test track. Pick a motor RPM,
press **Start run**, and compare runs at different speeds, settings and robot builds.

**Open `lf_simulator.html`.** It is one self-contained file: no internet, no install, no build step needed.
Double-click it (Chrome or Safari).

## What is in the page

- **Track board** (centre, to scale): white floor, black tape at the chosen width, crossing line, 5 cm gap,
  sharp 90° corner, labels and a 10 cm scale bar. The robot shows the chassis, the Arduino UNO, both wheels at
  the set spacing, the castor, the sensor bar and the two IR sensors exactly where the model puts them.
  A sensor turns red while it sees black. Arrows beside the wheels show wheel speed (green forward, red backward).
- **Camera**: *Whole track* or *Follow robot* (40 cm window). Scroll to zoom, drag to pan, double-click for the whole track.
- **Trail** of the point midway between the sensors, coloured by what the program is doing, with markers for
  sharp turns, "line lost → searching", crossings counted and where the run finished or failed.
- **Settings** (left): motor RPM (60–300; v_max = (RPM / 400) × (wheel ⌀ / 65 mm)), the LF3 constants with
  4 presets and a line-memory switch, the robot build (sensor spacing, sensors ahead, wheel spacing, wheel
  diameter, TAU, DEAD) and the line width.
- **Playback**: Start run, Pause/Resume, Restart, 0.1× to 4×, timeline scrubber. Space = play/pause, ← → = step.
- **Live readouts** (right): run clock and lap time, program state, both sensors, the rule being applied in
  plain words, signed motor PWM bars, wheel speeds, distance from the line, progress, crossings, line memory,
  the result card and the Serial Monitor output of the sketch.
- **Run history**: every run adds a row. Click a row to replay it, tick rows to overlay their trails,
  **Race** replays up to 4 ticked runs together.
- **Test all 72 combinations**: the reference robustness set for the current RPM and settings, run in background
  workers, shown as a 9 × 8 grid. Hover a cell for its conditions, click it to watch that run. When the C++
  reference result for those settings is known, the page shows it next to its own result.
- **How the program works** and **Show code** (followLine() with the running branch highlighted).

## How exact is it?

The page does not approximate the C++ simulator. It runs a line-by-line JavaScript port of
`reference/sim/sim.cpp` and of the sketch itself, and the port is checked against the C++ build:

| Check | Result |
|---|---|
| Track built in JS vs `centre.csv` / `strokes.csv` from `run_sim.py` | byte-identical, 3.53 m |
| 13 `run_sim.py` cases: RESULT lines (lap, mean/max deviation, junctions) | 13/13 identical |
| 13 `run_sim.py` cases: 5 ms trace files | 13/13 identical |
| Reference run, x / y / heading at full double precision, every 5 ms | 3617/3617 samples bit-identical |
| 7 robustness sets × 72 conditions: RESULT lines | 504/504 identical |

Full details are in [`test/validation_report.md`](test/validation_report.md).

## Re-running the checks

Needs `python3`, `g++` (C++17) and Node.js 16 or newer. For the browser check, Playwright with Chromium is also needed.

```bash
node test/validate.js
```

```bash
node test/browser_check.js
```

`validate.js` runs `reference/sim/run_sim.py`, builds the C++ variants with the reference's own
`variants.build()`, runs every case in C++ and in JavaScript, and writes `test/validation_report.md`.
`browser_check.js` opens the page from `file://` in headless Chromium, plays runs, runs the 72-combination test
(with and without Web Workers) and saves screenshots to `test/out/shots/`.

## Files

| Path | What it is |
|---|---|
| `lf_simulator.html` | the page (generated by `node build.js`; do not edit by hand) |
| `src/core/lf3_sketch.js` | LF3_Line_Follower.ino translated function by function |
| `src/core/world.js` | sim.cpp translated: robot model, Arduino functions, progress check |
| `src/core/track.js` | run_sim.py `build_path()` / `write_track()` translated |
| `src/core/mathlib.js` | glibc-identical `hypot`, correctly rounded `sin`/`cos`, CPython `math.dist`, printf formatting |
| `src/core/params.js` | RPM formula, presets, the 72-condition set |
| `src/ui/` | page template, style and app code |
| `build.js` | builds `lf_simulator.html` from `src/` (the same core files the tests check) |
| `reference/` | the sketch and the C++ / Python reference simulator, as supplied |
| `test/` | validation and browser checks, report, and the raw C++ reference outputs |

Changes to `reference/sim`: `variants.py` finds the sketch in `reference/code` (instead of the old absolute path),
and `robust.py` has an `if __name__ == "__main__":` guard around its sweep so `robust2.py` can import it.
